MinerU 安装与配置

本机安装（macOS / Linux）

当前 ALC 适配 MinerU 3.4.5 pipeline。先准备 Python 3.11；系统、内存和加速要求请核对 MinerU 官方安装说明。以下命令由你在终端手动执行，使用独立虚拟环境，不修改 ALC 的 Python 环境。

python3.11 -m venv "$HOME/.local/share/alc-mineru/venv"
"$HOME/.local/share/alc-mineru/venv/bin/python" -m pip install "mineru[pipeline]==3.4.5"
"$HOME/.local/share/alc-mineru/venv/bin/mineru" --version

先用一份小 PDF 验证，替换下面的输入和输出路径：

"$HOME/.local/share/alc-mineru/venv/bin/mineru" -p "/absolute/path/sample.pdf" -o "/absolute/path/ocr-output" -b pipeline

首次运行可能下载模型，需要额外磁盘空间和时间。依赖安装成功或版本检测成功不代表模型已经准备好；若下载或推理失败，请按官方文档处理后再试。

  1. 打开 ALC“模型与设置”→“PDF 识别”，选择“本机 MinerU”。
  2. 填入上面安装的可执行文件的绝对路径，例如 /Users/你的用户名/.local/share/alc-mineru/venv/bin/mineru。不要填写未展开的 $HOME 或 ~。
  3. 选择 OCR 语言，保存并检测配置，然后新建 PDF 任务。

连接已有服务

选择“已有 MinerU 服务”，填入支持 MinerU 3.4.5 FastAPI protocol 2 的服务地址。如需认证，按设置填写 token 的环境变量名，在启动 ALC 的环境中设置对应值。不要把密钥写进文档或发到聊天里。普通 OpenAI 兼容 API 地址不能代替 MinerU 服务。

在插件中使用

  1. 按上面的步骤安装 MinerU。
  2. 在使用 ALC 的对话中提供可执行文件的绝对路径，例如：“请为当前项目配置 MinerU，路径是 /Users/我的用户名/.local/share/alc-mineru/venv/bin/mineru，并检查是否可用。”
  3. 配置完成后，上传 PDF，说明需要翻译还是伴读。

如果使用已有服务，请提供 MinerU 服务地址，并说明是否同意将 PDF 上传到该服务。只需要文字时，可以说明“仅提取文字”；这种方式不保留图片，也无法读取扫描页。

配置按项目保存为 .ac/mineru.json，同项目插件和 Local Web 共用。修改配置只影响新建 Web 任务；旧任务不会自动改用新配置。
